# Read by tool/audit_public_repository.ps1, which checks the whole Git
# history in CI, and by test/repository_snowflake_test.dart, which checks
# the working tree on every `flutter test`. New test ids should use the
# fixture shape instead (one digit that is not zero, at least nine zeroes,
